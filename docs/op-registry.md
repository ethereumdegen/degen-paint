# The op registry

## Why this is the center of the design

A tool with a GUI, a CLI, an MCP server, an undo stack, and a scripting API normally implements
each capability five times and lets them drift. degen-paint implements each capability **once**, as an
op, and derives the five surfaces from it.

```rust
pub trait Op: Send + Sync {
    /// Stable dotted identifier, e.g. "raster.filter.gaussian-blur".
    fn id(&self) -> &'static str;

    /// Human summary used by --help, MCP tool descriptions, and generated docs.
    fn about(&self) -> &'static str;

    /// JSON Schema for the argument object, derived from the Rust type via schemars.
    fn schema(&self) -> schemars::Schema;

    /// Which document kinds this op can be applied to.
    fn modes(&self) -> &'static [Mode];

    /// Mutate the project. Pixel and buffer results go to the asset store;
    /// only references land in the document JSON.
    fn apply(&self, project: &mut Project, args: Value, cx: &mut OpCx) -> Result<OpEffect>;
}

pub struct OpEffect {
    pub changed: Vec<DocId>,
    pub created: Vec<ObjectId>,
    pub removed: Vec<ObjectId>,
    pub warnings: Vec<Warning>,
    pub cost: Option<Cost>,      // populated by AI ops
}
```

Derived from that single definition:

| Surface | How it is derived |
|---|---|
| CLI | `dpaint op <id> --flag value`, flags generated from the schema; `dpaint op <id> --help` prints it |
| MCP | one tool per op, `inputSchema` = the op schema, description = `about()` |
| GUI | Tauri command `invoke_op(id, args)`; panels are schema-driven forms |
| Undo | JSON-patch diff of the touched documents, no per-op inverse code |
| Journal | `{op, args, patch, effect}` appended to `history.jsonl` |
| Docs | `docs/ops/*.md` generated by `dpaint schema --markdown` |

**Adding a feature is adding one op.** Nothing else has to be touched for it to appear in the CLI,
in MCP, in the GUI, in history, and in the docs.

## Conventions

- Identifiers are `domain.object.verb`, lowercase, hyphenated verbs.
- Targets are **selectors**, never indices: `#lyr_sky`, `layer[type=text]`, `node[name^=bolt]`,
  `*` for all. Selectors resolving to zero objects are an error, not a silent no-op.
- Ops are pure functions of `(project, args)`. No hidden global state, so replay is exact.
- Ops that could destroy work (`flatten`, `rasterize`, `to-outlines`) are explicit verbs; nothing
  bakes implicitly.
- Query ops (`inspect.*`, `render.*`, `vector.measure.*`) never mutate and never journal.
- Every op validates fully before mutating anything — a failed op leaves the project untouched.

# v1 op catalog

## `project.*` — project and document lifecycle
| Op | Notes |
|---|---|
| `project.new` | name, initial document kind and size |
| `project.info` | query: documents, sizes, asset count, journal length |
| `doc.add` / `doc.remove` / `doc.rename` / `doc.duplicate` | mixed kinds in one project |
| `doc.set-active` | the default target for subsequent ops |
| `asset.import` | file or URL → content-addressed blob; returns hash and metadata |
| `asset.gc` | prune blobs unreachable from documents and journal |
| `history.undo` / `history.redo` / `history.checkpoint` / `history.replay` | checkpoints are named journal positions |
| `palette.set` / `palette.remove` | project-level named colors usable anywhere a color is accepted |
| `font.register` | embed a font file into the project so renders are reproducible |

## `raster.*`
**Canvas** — `canvas.resize`, `canvas.crop`, `canvas.trim`, `canvas.rotate`, `canvas.flip`,
`canvas.set-dpi`, `canvas.set-background`, `canvas.set-guides`

**Layers** — `layer.add` (`pixel` | `fill` | `gradient` | `text` | `shape` | `adjustment` |
`group` | `linked`), `layer.remove`, `layer.duplicate`, `layer.reorder`, `layer.rename`,
`layer.set` (opacity, blend, visible, locked), `layer.transform` (translate / scale / rotate /
skew / matrix / flip), `layer.group`, `layer.ungroup`, `layer.merge-down`, `layer.rasterize`,
`layer.from-selection`, `doc.flatten`

**Masks** — `mask.add`, `mask.remove`, `mask.apply`, `mask.invert`, `mask.from-selection`,
`mask.from-luminance`, `clip.set`

**Adjustments** — `adjust.curves`, `adjust.levels`, `adjust.brightness-contrast`, `adjust.hsl`,
`adjust.color-balance`, `adjust.exposure`, `adjust.channel-mixer`, `adjust.threshold`,
`adjust.posterize`, `adjust.invert`, `adjust.desaturate`, `adjust.lut`

**Filters** — `filter.gaussian-blur`, `filter.box-blur`, `filter.motion-blur`,
`filter.radial-blur`, `filter.unsharp`, `filter.sharpen`, `filter.noise-add`,
`filter.noise-reduce`, `filter.pixelate`, `filter.convolve` (arbitrary kernel),
`filter.morphology`, `filter.displace`, `filter.channel-op`, `filter.dither`, `filter.edge-detect`

**Selections** — `select.rect`, `select.ellipse`, `select.path`, `select.color-range`,
`select.wand` (flood tolerance, contiguous flag), `select.alpha`, `select.text`, `select.all`,
`select.none`, `select.invert`, `select.grow`, `select.shrink`, `select.feather`,
`select.to-path`. Every raster op accepts an optional selection scope.

**Paint** — `paint.stroke` (brush along a path: size, hardness, spacing, flow, pressure curve),
`paint.fill-bucket`, `paint.gradient` (linear / radial / angular / diamond), `paint.erase`,
`paint.pattern`

**Text** — `text.add`, `text.set`, `text.fit` (shrink-to-box), `text.to-shape`

**Effects** — `effect.drop-shadow`, `effect.inner-shadow`, `effect.stroke`, `effect.outer-glow`,
`effect.blur`, `effect.remove`

**Measure** (query) — `measure.bbox`, `measure.length`, `measure.area`, `measure.sample`,

## `ai.*` — optional, requires a provider key
| Op | Provider | Effect |
|---|---|---|
| `ai.image.generate` | fal | new pixel layer from a prompt |
| `ai.image.edit` | fal | instruction edit of a layer or the composite |
| `ai.image.inpaint` | fal | edit scoped to the current selection, used as the mask |
| `ai.image.outpaint` | fal | extend the canvas and fill |
| `ai.image.upscale` | fal | replace a layer with an upscaled blob |
| `ai.image.remove-background` | fal | generate a layer mask from a subject cutout |
| `ai.vector.generate` | Quiver | prompt → SVG → parsed into **editable** vector objects |
| `ai.vector.vectorize` | Quiver | raster layer or render → editable vector objects |
| `ai.texture.generate` | fal | PBR map set wired into a model material |
| `ai.provider.status` | — | which providers are configured, from where, and their limits |
| `ai.budget.set` / `ai.budget.status` | — | spend ceiling and running total |

See [`ai-providers.md`](./ai-providers.md).

## `render.*` / `inspect.*` — query only
`render.image` (scale, DPI, format, quality, background, region, annotate),
`render.turntable` (frames, elevation, lighting preset), `render.export` (SVG / PDF / GLB / GLTF),
`inspect.digest`, `inspect.tree`, `inspect.measure`, `inspect.histogram`, `inspect.palette`,
`lint.run`, `diff.images`.
